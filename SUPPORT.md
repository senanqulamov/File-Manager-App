# Support and enquiries

| You need | Start here |
| --- | --- |
| A demo, evaluation, or commercial discussion | [Demo enquiry](https://github.com/senanqulamov/File-Manager-App/issues/new?template=demo-request.yml) |
| Help running the sample environment | [Quick start](docs/QUICKSTART.md) |
| Help preparing a server | [Installation guide](docs/INSTALL.md) |
| To report a reproducible bug | [Bug report](https://github.com/senanqulamov/File-Manager-App/issues/new?template=bug-report.yml) |
| To propose an improvement | [Feature request](https://github.com/senanqulamov/File-Manager-App/issues/new?template=feature-request.yml) |
| To report a security concern | [Security reporting](SECURITY.md) |

GitHub issues are public. Use synthetic examples and redact names, tokens, passwords, internal addresses, and document content. Do not upload real company files or database backups.

For a bug, provide the version/commit, OS, reproduction steps, expected result, actual result, and a sanitised error excerpt. State whether you are using the local H2 demo or a PostgreSQL deployment.

Commercial support scope and response times are agreed separately. Opening a public issue does not create a support SLA. Existing customers should use the private channel specified in their agreement.
