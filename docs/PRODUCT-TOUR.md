# A closer look at Docket

Find a file, work on it, preserve its history, and share it with the right colleagues.

> All images on this page are supplied **design previews**, not screenshots captured from a validated release. Layout and branding may differ from the running JavaFX application. Capabilities below are based on the current source.

## Your starting point

![Home design preview](screenshots/02-home.png)

Home provides a starting point for recent work. My files is the personal workspace; Company holds shared company folders; Shared with me brings together items colleagues have shared.

## Browse and inspect

![Explorer design preview](screenshots/01-explorer.png)

Grid and details views, a clickable path, folder search, file-type filters, and familiar file operations support day-to-day work. The preview pane brings the selected item's information and actions closer to the file list.

## Open supported formats

![Viewer design preview](screenshots/03-viewer.png)

| Format/workflow | Behaviour and dependency |
| --- | --- |
| PDF | Page rendering, zoom, and navigation |
| Word, Excel, PowerPoint | Server-side LibreOffice conversion for page previews |
| PNG, JPG, GIF, BMP, WebP | Image viewing; validate representative files in the target environment |
| MP4, M4A, MP3, WAV | JavaFX media playback; compatibility depends on the file's codec and runtime |
| Text and code | Read-only text display |
| ZIP, 7z, TAR | Archive listing and extraction; validate supported compression variants |
| Other formats | Download or open in an associated external application |

RAR, HEIC, SVG, and MOV do not have dedicated in-app preview support. Folder drag-and-drop upload is not implemented.

## Edit and preserve versions

![Versions design preview](screenshots/04-versions.png)

Check out a file, edit its local working copy in the associated application, and check it back in with a comment. Version history lets a user open an older version or restore it as a new version. Concurrent edits and permission changes during check-out still need acceptance testing.

## Prepare documents

| Action | Current scope |
| --- | --- |
| Convert | Supported Office/PDF/image/text formats; FFmpeg adds media conversion. Availability depends on installed tools. PDF-to-Word conversion is not a promise of exact layout preservation. |
| Sign | Visible mark plus a PDF digital signature using a per-user certificate generated by Docket. Office input produces a signed PDF copy. |
| Lock / unlock | Password protection for supported PDF and Office files; other files use an encrypted ZIP container. This does not mean the entire storage volume is encrypted. |
| Stamp | Stamp supported PDFs and images; selected Office operations produce PDF copies. A visual stamp is not an approval workflow. |

![Signing design preview](screenshots/05-sign.png)

Signing certificates are self-generated and not automatically trusted by external recipients. Certificate trust and any required signature policy must be assessed separately. Scanned PDF text recognition is not implemented.

## Share with named colleagues

![Sharing design preview](screenshots/07-share.png)

Share files or folders from My files with view or edit access. Expiry options are one day, seven days, thirty days, or no expiry. This is internal account-based sharing; public anonymous sharing links are not advertised.

## Give IT an operating view

![User administration design preview](screenshots/08-admin-users.png)

Administrators manage accounts, quotas, company-folder ACLs, access requests, deleted items, and client updates. Company folders use person/group access rules with inheritance.

![Audit design preview](screenshots/10-admin-audit.png)

The activity log provides searchable application records and CSV export. It is not an independently verified, immutable compliance ledger. Server and database administrators remain within the system's trust boundary.

## Install on Windows

![Installer design preview](screenshots/12-installer.png)

The packaging scripts use jpackage and Inno Setup to build a Windows installer with Java included. They support a preconfigured server address and optional server-certificate import. A publisher-signed, tested installer has not been established by this repository review.
